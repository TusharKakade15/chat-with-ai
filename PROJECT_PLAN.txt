--------------------------------------------------------------------------------
1. EXECUTIVE SUMMARY & OBJECTIVE
--------------------------------------------------------------------------------
Transform the multi-AI Chrome Extension from a rigid, serial round-robin into a 
dynamic, natural "Virtual Engineering Team Room" group chat experience.

Key Innovation:
- Disguise AI identities: ChatGPT, Claude, and Gemini will interact as human 
  colleagues with distinct specialized engineering roles (e.g., Architect, Backend 
  Lead, DevOps/SRE) alongside the User (Product/Tech Lead).
- Eliminates AI sycophancy, polite disclaimers, and repetitive agreements.
- Strict output delimiters ([MESSAGE]...[/MESSAGE]) ensure deterministic, 
  zero-fluff scraping with instant parsing.
- Interactive Side Panel with Click-to-Navigate: Clicking any message in the 
  side panel activates the corresponding AI tab and smoothly scrolls directly to 
  that exact message response.

4. ZERO-FLUFF EXTRACTION PROTOCOL
--------------------------------------------------------------------------------
In content/chatgpt.js, content/claude.js, and content/gemini.js:
- Content scripts look specifically for the [MESSAGE]...[/MESSAGE] boundaries.
- Any conversational preambles ("Sure, here is my thought:") or UI footer junk are 
  automatically discarded.
- Streaming parser cleans text in real-time as chunks stream into the DOM.

Extraction Logic:
```javascript
function extractCleanResponse(raw) {
  const match = raw.match(/\[MESSAGE\]([\s\S]*?)\[\/MESSAGE\]/i);
  if (match && match[1].trim()) {
    return match[1].trim();
  }
  // Fallback if tag is partially streamed or omitted
  return raw.replace(/\[MESSAGE\]/i, '').replace(/\[\/MESSAGE\]/i, '').trim();
}
```

--------------------------------------------------------------------------------
5. CLICK-TO-NAVIGATE (JUMP TO EXACT POSITION IN AI TAB)
--------------------------------------------------------------------------------
How it works:
1. Message Tagging:
   - When each AI turn is saved in the Side Panel (chat.js), the message metadata 
     stores: { aiKey: 'chatgpt'|'claude'|'gemini', turnIndex: N, textSnippet: '...' }
2. Click Handler:
   - User clicks any message bubble in the Side Panel.
3. Tab Focus & Activation:
   - chat.js sends message to background.js: { type: 'FOCUS_AND_SCROLL', aiKey, turnIndex, textSnippet }
   - background.js calls chrome.tabs.update(tabId, { active: true }) and brings the browser window to front.
4. Smooth Scroll & Highlight:
   - background.js messages the content script: { type: 'SCROLL_TO_TURN', turnIndex, textSnippet }
   - Content script finds the message DOM element by turn index / text match, executes:
     element.scrollIntoView({ behavior: 'smooth', block: 'center' })
   - Triggers a brief highlight flash (pulse animation) on the target element.
